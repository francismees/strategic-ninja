# Source and reuse provenance register

Every third-party resource consulted in a way that influenced this build. **Inspection is not reuse.** Unless the "Reuse decision" says otherwise, no third-party text, code or data files were copied into this skill; only general methods were implemented in original wording and code. Resources mentioned in the research papers but not inspected (e.g. Karis, Superamped AI Marketing Skills, porter-strategy-skills, clawfu-skills, borghei/claude-skills, chefjefff/mckinsey-problem-solving, digital-marketing-pro) are **not listed** because they did not influence the build.

Inspection date for all rows: **2026-09-17**. Repository commits are the default-branch HEAD at inspection, obtained through the GitHub API. Licences were verified from the LICENSE file in the repository, not from the papers.
